# Velorun

**Simple to set up. Easy to use. Built for Paper and Velocity.**

Velorun is a lightweight command bridge that lets you execute Velocity proxy commands directly from your Paper server.

No complicated setup or custom scripts required. Install the Paper and Velocity components, configure your plugin message channel, and you're ready to go.

## Features

- **Easy to use:** Execute proxy commands from your Paper server.
- **Skript support:** Run proxy commands from Skript.
- **Configurable:** Set your own plugin message channel.
- **Command restrictions:** Configure which proxy commands are allowed.
- **Lightweight:** Designed to do one job without unnecessary complexity.

## Installation

1. Install the Velorun Paper component on your Paper server.
2. Install the Velorun Velocity component on your Velocity proxy.
3. Configure the plugin message channel on both sides.
4. Restart your server and proxy.
5. Use `/velorun <command>` from your Paper server.

**Example:**

`/velorun server cityplots`

This executes the `server cityplots` command through Velocity.

## Requirements

- A Paper server
- A Velocity proxy
- Both Velorun components

## Important

The Paper and Velocity components must use the same plugin message channel.

Check the configuration files for further options and restrictions.
